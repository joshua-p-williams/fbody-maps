# Design Principles

## 1. The base is vehicle-specific

The A-pillar saddle is allowed to be specific to the 1993–2002 GM F-body driver-side pillar. It should not contain accessory-specific geometry unless required by the interface.

## 2. The interface is standardized

Accessories should mount to a stable MAPS interface so that future accessories can be developed without redesigning the pillar base.

## 3. The scan is reference only

Raw photogrammetry output is expected to be lumpy and imperfect. Do not print the scan. Use the scan as a reference to build clean CAD geometry.

## 4. Keep it low profile

Avoid bulky universal ball-and-socket mounts where a flush or semi-flush joint is possible.

## 5. Prefer reversible installation

Use VHB tape, non-destructive clips, or existing trim retention where practical. Avoid drilling factory trim unless specifically desired.

## 6. Design for heat

Automotive interiors can get very hot. PLA is acceptable for fit prototypes but not recommended for final use. Prefer PETG, ASA, ABS, nylon, or other suitable materials.

## 7. Document every prototype

Every print should have a prototype log with:
- material
- printer
- orientation
- fit result
- problems
- next change
