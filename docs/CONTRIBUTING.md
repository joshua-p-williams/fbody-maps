# Contributing

This project is early-stage open-source hardware.

## Contributions Welcome

Useful contributions include:

- fitment testing
- CAD improvements
- accessory adapters
- print settings
- documentation
- photos
- Camaro compatibility validation
- passenger-side pillar validation

## Contribution Guidelines

- Keep source CAD files editable.
- Include exported STL only when source CAD is included.
- Document printer/material/settings for tested parts.
- Avoid uploading copyrighted or proprietary models.
- Use clear filenames and version numbers.
- Include photos for fitment claims when possible.

## File Naming

Recommended pattern:

```text
maps-base-apillar-firebird-driver-v0.1.FCStd
maps-base-apillar-firebird-driver-v0.1.stl
maps-accessory-holley-35-v0.1.FCStd
```
