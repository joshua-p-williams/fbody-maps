# Fitment Checklist

## Saddle Fit

- [ ] Base sits against pillar without rocking.
- [ ] Edges do not visibly lift.
- [ ] Part does not interfere with weather stripping.
- [ ] Part does not interfere with pillar reinstallation.
- [ ] Part does not block visibility excessively.
- [ ] Part leaves room for wire routing.
- [ ] VHB tape recesses align with stable contact areas.

## Interface Fit

- [ ] Accessory slides into rail/interface smoothly.
- [ ] Accessory has minimal wobble.
- [ ] Retention screw locks securely.
- [ ] Accessory can be removed without removing base.
- [ ] No sharp edges face occupants.

## Road/Vibration Test

- [ ] No rattling at idle.
- [ ] No rattling during road test.
- [ ] Accessory angle does not drift.
- [ ] Adhesive remains secure after heat exposure.
