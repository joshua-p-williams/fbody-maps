# MAPS-STD-001: Accessory Interface

Status: Draft

## Purpose

Define the standard mechanical interface between a MAPS vehicle base and MAPS-compatible accessories.

## Design Intent

The interface should be:

- Low-profile
- Easy to print
- Resistant to vibration
- Repeatable across accessories
- Serviceable without removing the pillar base

## Candidate Interface

Initial candidate: shallow vertical rail or dovetail-style slide interface with a retention screw.

## Open Decisions

- Rail width
- Rail height
- Rail taper angle
- Engagement length
- Retention screw size
- Heat-set insert usage
- Clearance tolerance
- Print orientation assumptions

## Draft Requirements

- Accessories must not rely on adhesive to remain attached to the base.
- Accessories should be removable without removing the pillar saddle.
- Accessory installation should require no more than one common hand tool.
- The interface should tolerate normal vehicle vibration.

## Proposed Fasteners

Initial candidates:

- M3 socket head cap screw
- M3 heat-set insert
- M4 screw for pivot cartridge where higher clamping force is needed

## Notes

Do not finalize this standard until the saddle prototype and dummy accessory block have been tested.
