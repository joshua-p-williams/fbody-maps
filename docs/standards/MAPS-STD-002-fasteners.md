# MAPS-STD-002: Fasteners and Inserts

Status: Draft

## Preferred Metric Hardware

| Use | Candidate |
|---|---|
| Small accessory retention | M3 socket head cap screw |
| Heat-set insert | M3 brass insert |
| Pivot clamping | M4 or M5 screw |
| Locking nut | Nylon insert locknut where applicable |

## Heat-Set Insert Notes

Use heat-set inserts only where repeated assembly/disassembly is expected.

Recommended practice:

- Add generous boss material around inserts.
- Avoid placing inserts too close to thin edges.
- Test insert pull-out strength on scrap prints first.

## Automotive Considerations

- Avoid loose nuts where they could rattle.
- Use threadlocker where appropriate.
- Consider nylon locknuts or captive nuts for vibration resistance.
