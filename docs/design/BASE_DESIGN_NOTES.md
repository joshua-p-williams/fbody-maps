# Base Design Notes

## Initial Base

The first base should be a simple add-on saddle that conforms to the driver-side A-pillar trim.

## Contact Area

Avoid wrapping around the entire pillar. A partial saddle with approximately 120–150 degrees of contact should be more forgiving and easier to print.

## Adhesion

Use recessed areas for automotive-grade 3M VHB tape.

Potential benefits:

- non-destructive install
- vibration damping
- compensates for minor surface mismatch
- easier iteration

## Wire Routing

Future versions should include a small wire channel or pass-through for display wiring.

## Finish

Final parts should have rounded edges and a surface finish that visually matches the factory interior.
