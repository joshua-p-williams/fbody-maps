# Low-Profile Pivot Joint Notes

## Design Direction

Avoid bulky ball-and-socket mounts. Use a low-profile cylindrical tilt joint for accessories that need vertical angle adjustment.

## Candidate Joint

A screw-clamped barrel hinge or cylindrical friction joint.

## Desired Behavior

- Flush or semi-flush profile
- Adjustable up/down tilt
- Resistant to vibration
- Tightenable with common hardware
- Replaceable or modular accessory adapter

## Options

### Screw-Clamped Barrel Hinge

Simple first version using printed hinge ears and an M4 or M5 screw.

### Serrated Friction Hinge

Adds radial teeth to prevent drooping.

### Pivot Cartridge

A separate cartridge that attaches to the MAPS interface and provides tilt adjustment for specific accessories.

## Recommendation

Do not integrate the pivot directly into the saddle in early prototypes. Validate the saddle first, then validate the interface, then add the pivot cartridge.
