# Phone Photogrammetry Scanning Guide

## App

Initial scan captured with KIRI Engine.

## Preparation

- Remove A-pillar trim from vehicle.
- Add painter's tape markers with unique Sharpie patterns.
- Use diffuse lighting.
- Avoid glossy surfaces.
- Use a textured or visually complex background if possible.

## Marker Suggestions

Use distinct markings:

- dots
- triangles
- arrows
- zig-zags
- numbers
- letters
- stars
- checker patterns

Avoid making every marker look the same.

## Capture Recommendations

- 80–150 photos
- Multiple height rings
- Good overlap between shots
- Keep the object stationary
- Move slowly
- Capture front, edges, and back

## Export Recommendation

Use OBJ for CAD reference because it preserves texture and imports widely.

## Notes

A lumpy scan is acceptable. The goal is to capture enough geometry to trace and design a clean saddle.
