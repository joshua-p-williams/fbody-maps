# Project Brief

## Project Name

`fbody-maps`

## Product Name

**MAPS — Modular Automotive Positioning System**

## Problem

Aftermarket display and gauge mounts are often single-purpose, bulky, and visually disconnected from the vehicle interior. A custom Holley EFI display mount for a 4th-gen F-body should be clean, low-profile, removable, and reusable for future accessories.

## Solution

Create a modular A-pillar mounting system consisting of:

1. A vehicle-specific A-pillar saddle base.
2. A standardized MAPS interface.
3. Interchangeable accessory adapters.

## First Use Case

Mount a Holley 3.5-inch Terminator X display on the driver-side A-pillar of a 2002 Pontiac Trans Am.

## Long-Term Vision

A reusable modular mounting ecosystem for enthusiast vehicles, starting with 1993–2002 GM F-body platforms.
