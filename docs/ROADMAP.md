# Roadmap

## Phase 0 — Reference Capture

- [ ] Remove driver-side A-pillar trim.
- [ ] Add temporary photogrammetry markers.
- [ ] Scan with KIRI Engine or similar app.
- [ ] Export OBJ reference mesh.
- [ ] Store raw scan locally or in Git LFS if needed.
- [ ] Create processed/cropped scan for CAD reference.

## Phase 1 — Saddle Fit

- [ ] Import scan into FreeCAD.
- [ ] Crop to relevant mounting region.
- [ ] Create first clean saddle surface.
- [ ] Print prototype in PLA.
- [ ] Test fit on actual pillar trim.
- [ ] Log fitment issues.
- [ ] Iterate until base conforms well.

## Phase 2 — Base Features

- [ ] Add VHB tape recesses.
- [ ] Add optional wire channel.
- [ ] Add edge radii.
- [ ] Evaluate print orientation.
- [ ] Test fit again.

## Phase 3 — MAPS Interface

- [ ] Define interface standard.
- [ ] Add low-profile rail or slide-on feature.
- [ ] Design dummy accessory block.
- [ ] Validate slide fit and retention.
- [ ] Add locking screw or retention feature.

## Phase 4 — First Accessory

- [ ] Model Holley 3.5-inch display adapter.
- [ ] Add low-profile cylindrical tilt joint.
- [ ] Add wire-routing path.
- [ ] Print and test.
- [ ] Validate driver visibility and obstruction.

## Phase 5 — Release

- [ ] Export release STL files.
- [ ] Export STEP files.
- [ ] Add print settings.
- [ ] Add install guide.
- [ ] Add photos.
- [ ] Tag v1.0.
