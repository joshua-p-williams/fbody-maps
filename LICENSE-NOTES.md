# License Notes

Choose a license before publishing printable files publicly.

Suggested approach:

- Documentation: Creative Commons Attribution 4.0 International (CC BY 4.0)
- CAD/printable hardware: CERN Open Hardware Licence Version 2 - Strongly Reciprocal (CERN-OHL-S) or Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0)
- Helper scripts: MIT License

## Recommendation

For a community hardware project where improvements should remain open, consider:

- `CERN-OHL-S-2.0` for CAD and hardware design files
- `CC-BY-4.0` for documentation
- `MIT` for scripts

Do not publish third-party scans, logos, or proprietary assets unless you have the right to do so.
